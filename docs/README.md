# Documentation index

- `usage.md`: the styling reference carried over from upstream (cards, rows, badges, elements, templates, DOM navigation, `mod-card`).
- `design.md`: how the patches attach, how theme YAML is loaded, and why the frontend surrogate was removed.
- `decisions.md`: dated decisions with their reasons.
- `operations.md`: theme keys including the `tools` alias, resource switch, troubleshooting.
- `security.md`: trust boundaries and controls.
- `quality-scale.md`: an honest bar for a HACS frontend plugin and where this repository stands.
- `backlog.md`: open items, including the unreproduced upstream issues.
- `THIRD_PARTY.md`: every borrowed file with its source and commit.

The three upstream files at the repository root are kept as reference: `README-application.md` (which elements are patched), `README-themes.md` (theme keys), `README-developers.md` (`applyToElement`).
