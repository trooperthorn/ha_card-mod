# Quality scale

Home Assistant's integration quality scale applies to backend integrations only. This adapts the same tiers to what matters for a HACS frontend plugin that patches frontend internals, and records where this repository stands. A box is ticked only when the bar is met today.

## Bronze

- [x] README documents installation, the `extra_module_url` requirement, and how to switch from upstream
- [x] MIT licence with both copyright holders; borrowed code listed in `docs/THIRD_PARTY.md`
- [x] CI on every push and pull request: lint, tests, build
- [x] `hacs.json` names the file and declares the 2026.8.0 floor
- [x] No abandoned direct dependency (Babel, `rollup-plugin-terser` and `rollup-plugin-typescript2` removed)

## Silver

- [x] Unit tests for the logic that can run in jsdom: YAML loading, dialog param sanitising, theme alias and indirection, theme index, icon usage flag (33 cases)
- [x] A hook-contract test that checks the pinned frontend tag for every patched private method and selector
- [x] CHANGELOG maintained by hand per CalVer release
- [x] Issue templates kept from upstream
- [ ] A browser-level test that loads the bundle against a real frontend build and asserts a style is applied (the upstream `test/` docker-compose harness exists but is not wired into CI)

## Gold

- [x] Tagged releases cut automatically from `main` with the bundle as the release asset, reproducible from the committed `dist/`
- [x] `npm audit` clean at moderate level; CodeQL on every push; actions SHA-pinned; weekly scheduled runs
- [x] Known limitations stated rather than assumed away (`docs/backlog.md`, `docs/security.md`)
- [x] Performance work measured against a stated cost model (PR #610's profile: ~900 `getComputedStyle` calls per dashboard load from icons alone)
- [ ] Live verification on Home Assistant 2026.9.1 with a theme that defines `card-mod-*-yaml` keys (not yet done for this fork)
- [ ] Reproduction and fix or dismissal of upstream #613 (sections editor) and #614 (refresh loop)

## Platinum

- [ ] A frontend-version compatibility matrix maintained per release, generated by running the hook-contract test against several tags
- [ ] Strategy-section `card_mod` verified live (the `_createCards` patch is present and hook-checked but its effect has not been observed on 2026.9)
- [ ] Bundle size budget enforced in CI
